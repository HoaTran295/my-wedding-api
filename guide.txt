===== Trang quản lý danh sách tham dự (ds-tham-du.html) =====
1. Chạy migration 1 lần trên database "wedding":
   migrations/001_add_is_deleted_to_rsvp_responses.sql
   migrations/002_add_is_seen_to_rsvp_responses.sql
2. Chạy lại server như bình thường:
   nohup go run main.go &
3. API quản lý (không cần đăng nhập):
   GET    /api/v1/wedding/admin/rsvp       -> danh sách chưa soft delete (tham dự lên trước, mới nhất trước)
   DELETE /api/v1/wedding/admin/rsvp/:id   -> soft delete (is_deleted = 1)
   PATCH  /api/v1/wedding/admin/rsvp/:id   -> body {"is_visible": true/false} và/hoặc {"is_seen": true/false}

===== Xem trước link có tên khách trên Zalo / Messenger =====
1. Sửa INVITE_INDEX_PATH trong startup.sh (hoặc wedding-api.service) thành đường dẫn
   index.html của thiệp trên server, rồi chạy lại ./startup.sh
2. Thêm cấu hình trong nginx-invite.conf vào nginx, rồi: sudo nginx -t && sudo systemctl reload nginx
3. Kiểm tra trên server:
   curl -s "https://cuoi-hoa-tuyet.htsolution.top/index.html?invite-name=Anh+Minh" | grep og:title
   -> phải thấy "Thân mời Anh Minh tham dự đám cưới Trần Hòa &amp; Ánh Tuyết"
